# Go Is Statically Typed

Go enforces static typing meaning variable types are known before the code runs. That means your editor and
the compiler can display type errors before the code is ever run, making development easier and faster.


Contrast this with most dynamically typed languages like JavaScritp and Python... Dynamic typing often leads
to subtle bugs that are hard to detect. The code must be run to catch syntax and type errors.

# Concatenatiing Strings

Two strings can be concatenated with the + operator. But the compiler will not allow you to 
concatenate a string variable with an int or a float64
