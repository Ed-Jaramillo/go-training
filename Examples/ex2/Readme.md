# Declaring a Variable

The var keyword is used to declare a variable. For example, to
declare an integer variable called *mySkillIssues* and assign it the value 42


// create a new variable, it defaults to 0
// (the "zero value" for ints)

var mySkillIssues integer

// overwrite the zero value with 42
mySkillIssues = 42
