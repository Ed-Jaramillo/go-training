We need to calculate the total cost for a batch of messages, and update
the user's balance if they have enough money.

# Assignment

1. Set finalCost to the bulkMessageCost
2. If the user is a premium user, apply the discountRage to the finalCost:
	2.1 For example, a discountRate of 0.10 means the discounted price per message would be 90% of the original
	price
3. If the user has enough money in their accountBalance:
	3.1 Dedict finalCost from their accountBalance
	3.2 Print the purchaseSuccessMessage
